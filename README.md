# Customer Analysis Power BI Dashboard

A comprehensive analytics dashboard built with Power BI that visualizes customer demographics, revenue hotspots, and churn risk to drive data-driven business decisions.

## 📊 Overview

This Power BI dashboard provides actionable insights into customer behavior, purchasing patterns, and retention metrics. It enables businesses to identify high-value customer segments, predict churn risks, and optimize marketing strategies.

## ✨ Features

- **Customer Demographics Analysis**: Visualize customer distribution by age, gender, location, and other demographic factors
- **Revenue Hotspots**: Identify top-performing regions, customer segments, and product categories
- **Churn Risk Assessment**: Predict and visualize customers at risk of churning with risk indicators
- **Interactive Filtering**: Dynamic filters and slicers for custom data exploration
- **KPI Tracking**: Monitor key performance indicators including:
  - Customer Lifetime Value (CLV)
  - Customer Acquisition Cost (CAC)
  - Retention Rate
  - Average Order Value (AOV)
  - Churn Rate

## 🚀 Getting Started

### Prerequisites

- Microsoft Power BI Desktop (latest version recommended)
- Access to customer data sources (CSV, SQL database, or other supported formats)

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/Jasmine25005/Customer-Analysis-PowerBI.git
   ```

2. Open the Power BI file (`.pbix`) with Power BI Desktop

3. Connect to your data sources and refresh the data

### Data Requirements

The dashboard expects the following data fields:

- **Customer Information**: Customer ID, Name, Age, Gender, Location
- **Transaction Data**: Order ID, Date, Amount, Product Category
- **Engagement Metrics**: Last Purchase Date, Purchase Frequency, Support Tickets
- **Churn Indicators**: Account Status, Engagement Score

## 📈 Usage

1. **Open the Dashboard**: Launch the `.pbix` file in Power BI Desktop
2. **Refresh Data**: Click "Refresh" to load the latest data from your sources
3. **Explore Insights**: Use filters and slicers to drill down into specific segments
4. **Export Reports**: Generate and export reports for stakeholder presentations

## 🛠️ Technologies Used

- **Power BI Desktop**: Primary dashboard development tool
- **DAX (Data Analysis Expressions)**: For calculated columns and measures
- **Power Query**: Data transformation and cleaning
- **M Language**: Advanced data shaping and preparation
